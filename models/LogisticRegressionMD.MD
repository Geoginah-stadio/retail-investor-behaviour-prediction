## 3. Data Split and Evaluation Method

The notebook uses an **80/20 train-test split**:

- **Training data:** 80%
- **Testing data:** 20%
- **Random state:** 42
- **Stratification:** Yes

Stratification is used to preserve the distribution of the `dormant` target classes between the training and testing datasets.

The final performance metrics are calculated on the held-out test set. This provides an evaluation of the model on observations that were not used to train the model.

The prediction threshold is:

`0.50`

Predicted probabilities greater than or equal to 0.50 are classified as the positive class (`Dormant`).

---

## 4. Preprocessing

Logistic Regression is sensitive to feature scale, so the notebook applies the following preprocessing:

### Numerical variables

- Missing values are replaced using the **median**.
- Numerical variables are standardised using `StandardScaler`.

### Categorical variables

- Missing values are replaced using the **most frequent category**.
- Categorical variables are transformed using **one-hot encoding**.
- `handle_unknown="ignore"` is used so that previously unseen categorical values do not cause errors during transformation.

The preprocessing and Logistic Regression model are combined in a single scikit-learn pipeline.

## 6. Performance Metrics

The notebook calculates the following metrics using the held-out test dataset:

### Accuracy

Accuracy measures the proportion of all predictions that were classified correctly.

```text
Accuracy = Correct Predictions / Total Predictions
```

### Precision

Precision measures the proportion of observations predicted as dormant that were actually dormant.

```text
Precision = True Positives / (True Positives + False Positives)
```

### Recall

Recall measures the proportion of actual dormant observations that were correctly identified by the model.

```text
Recall = True Positives / (True Positives + False Negatives)
```

### F1-score

The F1-score is the harmonic mean of precision and recall.

```text
F1 = 2 × (Precision × Recall) / (Precision + Recall)
```

### ROC-AUC

ROC-AUC measures the model's ability to distinguish between the dormant and non-dormant classes across different classification thresholds.

The ROC-AUC calculation uses the predicted probability of the `Dormant` class rather than the final 0/1 predictions.

## 11. Statistical / Evaluation Methods Used

The Model 1 evaluation uses the following statistical and model-evaluation methods:

1. **Stratified train-test split** — an 80/20 split is used while preserving the target-class distribution.
2. **Accuracy** — measures overall classification correctness.
3. **Precision** — measures the correctness of positive/dormant predictions.
4. **Recall** — measures how many actual dormant observations are identified.
5. **F1-score** — combines precision and recall into a single metric.
6. **ROC-AUC** — evaluates discrimination between dormant and non-dormant customers across classification thresholds.
7. **Confusion matrix** — examines the four categories of classification outcomes.
8. **Classification report** — provides class-level precision, recall, F1-score and support.

No separate hypothesis test, confidence interval, or statistical significance test is implemented in the supplied notebook. The evaluation is based on the model-performance metrics and diagnostic plots described above.
